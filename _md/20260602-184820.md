- コードブロックを `MarkdownCodeBlock` として分離し、コード単位の Copy ボタンを追加した。
- 同一パスのテキスト/PDFピン留め重複を防ぎ、既存ピン留めを前面化するようにした。
- テキストピン留めに `floatingStacks` を追加し、ドラッグ終了時に同カテゴリ・同拡張子・別ファイルが重なっていればタブ化するようにした。
- スタックタブの切替と、タブ内プレビューの close / edit / save / Markdown checkbox 操作を追加した。
- カテゴリヘッダークリックで同カテゴリのホバー/ピン留め/スタック/PDFを前面化する処理を追加した。
- PDF読み方向ボタンを `spreadMode === "double"` の時だけ表示するようにした。
- 検索ハイライトを透過蛍光グリーン背景と点滅アニメーションに変更した。

## 4. 実装詳細

- Markdown強化
  - `---` / `***` を `.mdHorizontalRule` として表示。
  - `>` 引用を `.mdQuote` として表示。
  - 箇条書きと番号付きリストはインデント量から `--md-indent` を設定。
  - コードブロックは Markdown 解釈せず、選択コピーと Copy ボタンに対応。

- タブ重ね
  - `getFloatingCategoryId()` / `getFloatingExtension()` / `canStackFloatingPreviews()` / `rectsOverlap()` を追加。
  - ドラッグ終了時のみ `tryStackPinnedPreview()` を呼び、条件に合うピン留めテキストだけを `floatingStacks` にまとめる。
  - スタック内は `activePreviewId` によって表示対象を切り替える。

- 重複防止
  - `normalizePathKey()` とパス一致検索を追加。
  - 同じファイルを再ピン留めしようとした場合は新規作成せず既存表示を前面化。
  - 同じファイルのホバー開始時も、既存ピン留めがあれば前面化して一時ホバーを作らない。

- カテゴリ連動
  - `bringCategoryFloatingPreviewsToFront()` を追加。
  - `GenreGrid` のヘッダークリックに接続し、開閉ボタンは `stopPropagation()` で分離。

- 検索ハイライト
  - `.searchHighlight` を蛍光グリーンの透過背景、outline、box-shadow、pulse animation に変更。
