# 作業ログ: 20260602-191941

## 1. 指示内容

- 同じファイル/フォルダ/アプリ/URLを別カテゴリや別セルに重複登録できないようにする。
- 前回追加したホバー/ピン留めのタブ重ね機能を削除する。
- 検索時のハイライトを、アイコン背景ではなくアイコン枠が光る表現に変更する。

## 2. 対応内容

- 登録パス正規化用の `normalizeRegisteredPath()` を追加した。
- ワークスペース全体から同じパスの既存登録を探す `findExistingItemByPath()` を追加した。
- 重複登録時に既存登録のカテゴリ、座標、表示名、パスを確認ダイアログで表示するようにした。
- OK時のみ既存登録を削除してから新しいセルへ登録するようにした。
- キャンセル時は登録処理を中断し、既存データを変更しないようにした。
- `floatingStacks`、`stackId`、スタック生成/切替/表示UI、スタック用CSSを削除した。
- 検索ハイライトCSSから背景変更を削除し、蛍光グリーンの枠線発光アニメーションへ変更した。

## 3. 変更ファイル

- `src/App.jsx`
- `src/styles.css`
- `_md/20260602-191941.md`

## 4. 実装詳細

- 同一ファイル重複登録防止
  - `saveItemAt()` で登録直前に `findExistingItemByPath(pathValue)` を実行。
  - 既存登録がある場合、`confirmMoveExistingItem()` で既存情報を表示。
  - OK時のみ `api.deleteItem()` で既存登録を削除し、その後 `api.saveItem()` で新規登録。
  - 移動先セルに別アイテムがある場合は従来通り登録を止める。

- タブ重ね機能削除
  - `floatingStacks` state と関連関数を削除。
  - ドラッグ終了時のスタック判定を削除。
  - `floatingPreviewStack` 系の JSX/CSS を削除。
  - 複数ピン留め、前面制御、移動、リサイズは維持。

- 検索ハイライト枠線化
  - `.searchHighlight` の `radial-gradient` 背景を削除。
  - `outline`、`border-color`、`box-shadow` による枠線発光へ変更。
  - `searchHighlightBorderPulse` で枠線と外側光のみ点滅させるようにした。
