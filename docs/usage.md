# 使い方

GridDesk は、ワークスペースフォルダを開いてから利用します。登録情報、配置情報、設定、バックアップはワークスペース内に保存されます。

## 初回起動

1. Electron アプリを起動します。
2. Welcome 画面で `新規ワークスペース` または `既存ワークスペース` を選択します。
3. フォルダ選択ダイアログで利用するワークスペースフォルダを選びます。

ワークスペースが初期化されると、`launcher.db` と設定ファイル、関連フォルダが作成されます。

## ワークスペース作成

`New` または `新規ワークスペース` からフォルダを選択します。選択したフォルダ内に次の構成が作成されます。

```text
launcher.db
settings.json
path_aliases.json
icons/
backups/
exports/
```

## 既存ワークスペースを開く

`Open` または `既存ワークスペース` から既存フォルダを選択します。最近開いたワークスペースは Welcome 画面にも表示されます。

## ジャンル追加

サイドパネルの `ジャンル管理` で、ジャンル名、列数、行数を入力して `ジャンル追加` を押します。

## ジャンル名変更

`変更対象ジャンル` を選び、`ジャンル名` の入力欄を編集します。現在の実装では入力変更時に即時保存されます。

## セルグリッドの使い方

ジャンルごとに `cols x rows` のセルグリッドが表示されます。各セルには `x,y` のセル番号が表示されます。

| 操作 | 動作 |
| --- | --- |
| 空セルクリック | 登録モード ON ならフォーム内容を登録 |
| アイコンシングルクリック | アイコン選択 |
| アイコンダブルクリック | 対象ファイル/フォルダ/URL を開く |
| アイコンドラッグ | 別セルへ移動 |
| セル右クリック | 基本メニューを表示 |

## ファイル/フォルダ/URL の登録

1. `セル登録` パネルでジャンルを選択します。
2. 表示名、パス/URL、種類を入力します。
3. 登録モードを ON にします。
4. 登録したいセルをクリックします。

`Clipboard` でクリップボードのテキストをパス欄に読み込めます。`Select` でファイルまたはフォルダを選択できます。

## ドラッグ＆ドロップ登録

OS からファイルまたはフォルダをセルへドロップすると、そのセルに登録します。URL やテキストをドロップした場合も、取得できたテキストをパスとして登録します。

削除済みセルや既にアイコンがあるセルには登録できません。

## アイコンのドラッグ移動

登録済みアイコンを別セルへドラッグします。移動先セルが空いていれば `items.x` / `items.y` が更新されます。

現在の重複時挙動はキャンセルです。入れ替え、上書き、空きセル自動配置は今後実装予定です。

## ダブルクリック起動

アイコンをダブルクリックすると対象を開きます。

| 対象 | 起動方式 |
| --- | --- |
| URL | `shell.openExternal` |
| ローカルファイル/フォルダ | `shell.openPath` |

起動に失敗した場合はトーストにエラーを表示します。リンク切れの永続マーク表示は今後実装予定です。

## 右クリックメニュー

現在の実装では、以下の基本操作に対応しています。

| 対象 | メニュー |
| --- | --- |
| アイコン | 開く、場所を開く、削除 |
| 空セル | ここに登録 |

名前変更、パス変更、ジャンル移動、プロパティ表示は今後実装予定です。

## セル削除/復活

`セル削除` を ON にしてセルをクリックすると、そのセルを削除済みにします。削除済みセルは斜線表示になり、アイコンを配置できません。

現在の実装では、削除済みセルを `セル削除` ON のままクリックすると復活します。専用メニューによる復活 UI は今後整理予定です。

## バックアップ

`Backup` ボタンで手動バックアップを作成できます。また、起動時と DB 更新前に自動バックアップします。

バックアップ対象:

- `launcher.db`
- `settings.json`
- `path_aliases.json`

保存先:

```text
backups/
```

## PC 乗り換え時の移行方法

1. ワークスペースフォルダを新 PC にコピーします。
2. GridDesk で `Open` からコピー先フォルダを開きます。
3. 絶対パスが変わったアイコンは、今後実装予定のパス修正 UI で修正する想定です。

現在は `path_aliases.json` の生成と alias 解決の一部に対応していますが、編集 UI や一括変換は未実装です。
