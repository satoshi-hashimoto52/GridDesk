# テスト観点

GridDesk は MVP 段階のため、現時点では手動テストを中心に確認します。自動テストは今後追加予定です。

## 開発環境

- [ ] `npm install` が成功する
- [ ] `sqlite3 --version` が成功する
- [ ] `npm run dev` で Vite が起動する
- [ ] `npm run electron` で Electron が起動する
- [ ] `npm start` で Vite と Electron が連携して起動する
- [ ] `npm run build` が成功する
- [ ] `node --check electron/main.cjs` が成功する
- [ ] `node --check electron/preload.cjs` が成功する

## ワークスペース作成

- [ ] 新規フォルダを選択できる
- [ ] `launcher.db` が作成される
- [ ] `settings.json` が作成される
- [ ] `path_aliases.json` が作成される
- [ ] `icons/`, `backups/`, `exports/` が作成される
- [ ] 初期ジャンル `General` が作成される
- [ ] 最近開いたワークスペースに表示される

## DB 初期化

- [ ] `genres` テーブルが作成される
- [ ] `items` テーブルが作成される
- [ ] `disabled_cells` テーブルが作成される
- [ ] `app_settings` テーブルが作成される
- [ ] `path_aliases` テーブルが作成される
- [ ] `idx_items_genre_cell` が作成される

確認例:

```bash
sqlite3 /path/to/workspace/launcher.db ".schema"
```

## ジャンル追加/変更/削除

- [ ] ジャンル名を入力して追加できる
- [ ] 列数/行数が反映される
- [ ] ジャンル名変更が保存される
- [ ] 列数/行数変更が保存される
- [ ] ジャンル折りたたみ状態が保存される
- [ ] ジャンル削除時に確認が出る
- [ ] ジャンル削除で関連アイコンと削除済みセルが削除される
- [ ] 同名ジャンル追加時にエラー表示される

## セル表示

- [ ] 指定した列数/行数でセルが表示される
- [ ] セル番号が表示される
- [ ] 削除済みセルが斜線表示になる
- [ ] ジャンル折りたたみ時にセルが非表示になる

## アイコン登録

- [ ] 手入力したパスを空セルへ登録できる
- [ ] URL を登録できる
- [ ] `Select` でファイルを選択して登録できる
- [ ] `Select` でフォルダを選択して登録できる
- [ ] `Clipboard` からパスを読み込める
- [ ] ファイルドロップで登録できる
- [ ] フォルダドロップで登録できる
- [ ] 既存セルへの登録がキャンセルされる
- [ ] 削除済みセルへの登録がキャンセルされる
- [ ] 同じ path の再登録で既存 item が更新される

## ドラッグ移動

- [ ] アイコンを空セルへ移動できる
- [ ] 移動後に DB の `x` / `y` が更新される
- [ ] 既存アイコンがあるセルへの移動がキャンセルされる
- [ ] 削除済みセルへの移動がキャンセルされる

## ダブルクリック起動

- [ ] ローカルファイルが開く
- [ ] ローカルフォルダが開く
- [ ] URL が既定ブラウザで開く
- [ ] 存在しないパスでエラー表示される
- [ ] alias path が `path_aliases.json` に基づいて解決される
- [ ] relative path がワークスペース基準で解決される

## 右クリックメニュー

- [ ] アイコン右クリックでメニューが出る
- [ ] `開く` が動作する
- [ ] `場所を開く` が動作する
- [ ] `削除` が動作する
- [ ] 空セル右クリックで `ここに登録` が出る

## セル削除/復活

- [ ] セル削除モード ON でセルを削除できる
- [ ] 削除済みセルが DB に保存される
- [ ] 削除済みセルにアイコンが表示されない
- [ ] 削除済みセルへ登録できない
- [ ] 削除済みセルを復活できる

## バックアップ

- [ ] ワークスペース読込時にバックアップが作成される
- [ ] ジャンル変更前にバックアップが作成される
- [ ] アイコン変更前にバックアップが作成される
- [ ] セル変更前にバックアップが作成される
- [ ] `Backup` ボタンで手動バックアップが作成される
- [ ] 世代数上限を超えた古いバックアップが削除される

## PC 移行

- [ ] ワークスペースフォルダを別の場所へコピーして開ける
- [ ] DB のジャンル/アイコン配置が維持される
- [ ] 相対パスがコピー先ワークスペース基準で解決される
- [ ] 絶対パスが変わるケースでは起動失敗が表示される
- [ ] alias path の解決を確認する

## 異常系

- [ ] `sqlite3` が存在しない場合にエラーが表示される
- [ ] DB ファイルが壊れている場合に起動失敗を把握できる
- [ ] 同名ジャンルで DB 制約エラーになる
- [ ] 同一セル重複で DB 制約エラーにならないよう renderer が止める
- [ ] 読み取り専用フォルダでバックアップ/DB 更新が失敗する

## macOS / Windows 差分

- [ ] macOS でファイル/フォルダ選択が動作する
- [ ] macOS で `shell.openPath` が動作する
- [ ] Windows で `.exe`, `.bat`, `.cmd`, `.lnk` の種類判定を確認する
- [ ] Windows のパス区切りとドライブレターを確認する
- [ ] ネットワークパスや UNC パスを確認する

## npm audit

- [ ] ネットワーク利用可能な環境で `npm audit` を実行する
- [ ] ネットワーク制限時の失敗をビルド失敗と切り分ける
- [ ] 脆弱性修正で破壊的変更が必要な場合は別タスクとして扱う
