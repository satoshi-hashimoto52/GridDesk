# 操作仕様

このドキュメントでは、現在の MVP 実装と今後実装予定の操作を分けて整理します。

## 基本操作

| 操作 | 現在の挙動 | 状況 |
| --- | --- | --- |
| シングルクリック | アイコンを選択。空セルは登録モード ON なら登録 | 実装済み |
| ダブルクリック | アイコンの対象を開く | 実装済み |
| ドラッグ | アイコンを別セルへ移動 | 実装済み |
| 右クリック | コンテキストメニュー表示 | 一部実装 |
| Delete キー | アイコン削除 | 今後実装予定 |
| F2 キー | 名前変更 | 今後実装予定 |

## ジャンル操作

| 操作 | 現在の挙動 | 状況 |
| --- | --- | --- |
| ジャンル追加 | 名前、列数、行数を指定して追加 | 実装済み |
| ジャンル名変更 | 入力変更時に保存 | 実装済み |
| 列数/行数変更 | 入力変更時に保存 | 実装済み |
| ジャンル削除 | 確認後に削除。関連 item/cell も cascade | 実装済み |
| 折りたたみ | ジャンルヘッダーのボタンで切替 | 実装済み |
| 並び替え | `sort_order` はあるが UI 未実装 | 今後実装予定 |
| メモ編集 | DB カラムはあるが UI 未実装 | 今後実装予定 |

## セル操作

| 操作 | 現在の挙動 | 状況 |
| --- | --- | --- |
| 空セルクリック | 登録モード ON ならフォーム内容を登録 | 実装済み |
| セル削除 | セル削除モード ON でクリック | 実装済み |
| セル復活 | 削除済みセルをセル削除モード ON でクリック | 実装済み |
| 削除済みセル表示 | 斜線表示 | 実装済み |
| 削除済みセルへの配置禁止 | 登録/移動を禁止 | 実装済み |
| セル番号表示切替 | 常時表示。設定切替 UI は未実装 | 今後実装予定 |

## アイコン登録

| 登録方法 | 現在の挙動 | 状況 |
| --- | --- | --- |
| 手入力 | パス/URL を入力してセルクリック | 実装済み |
| ファイル/フォルダ選択 | `Select` から選択 | 実装済み |
| クリップボード | `Clipboard` でテキスト読込 | 実装済み |
| ドラッグ＆ドロップ | セルへドロップ | 実装済み |
| 右クリックから登録 | 空セルメニューの `ここに登録` | 一部実装 |
| パス整形 | 基本的な種類判定のみ | 今後実装予定 |

## アイコン移動

| 条件 | 挙動 |
| --- | --- |
| 移動先が空セル | 移動する |
| 移動先が削除済みセル | 移動しない |
| 移動先に既存アイコンあり | キャンセル |

## セル重複時の挙動

現在の実装は「移動をキャンセルする」です。

| モード | 状況 |
| --- | --- |
| 上書きする | 今後実装予定 |
| 入れ替える | 今後実装予定 |
| 移動をキャンセルする | 実装済み |
| 空きセルへ自動配置する | 今後実装予定 |

DB 側でも `idx_items_genre_cell` により、同じジャンル内の同じセルに有効なアイコンを複数置かない制約があります。

## 起動失敗時の挙動

| 状況 | 現在の挙動 | 状況 |
| --- | --- | --- |
| ファイルが存在しない | `shell.openPath` のエラーをトースト表示 | 実装済み |
| URL が開けない | 例外をトースト表示 | 実装済み |
| リンク切れとしてマーク | 永続的な表示は未実装 | 今後実装予定 |
| パス修正画面 | 未実装 | 今後実装予定 |

## 右クリックメニュー

| 対象 | メニュー | 状況 |
| --- | --- | --- |
| アイコン | 開く | 実装済み |
| アイコン | 場所を開く | 実装済み |
| アイコン | 削除 | 実装済み |
| アイコン | 名前変更 | 今後実装予定 |
| アイコン | パス変更 | 今後実装予定 |
| アイコン | ジャンル移動 | 今後実装予定 |
| アイコン | プロパティ | 今後実装予定 |
| 空セル | ここに登録 | 実装済み |
| セル | セル削除/復活メニュー | 今後実装予定 |

## バックアップ作成タイミング

| タイミング | 状況 |
| --- | --- |
| アプリ起動時/ワークスペース読込時 | 実装済み |
| DB 変更前 | 実装済み |
| 手動バックアップ | 実装済み |
| アプリ終了時 | 今後実装予定 |

## リンク切れ表示

現在は起動失敗時にトーストを表示します。アイコンを薄くする、警告マークを付ける、リンク切れ一覧を表示する機能は今後実装予定です。
