# GridDesk 概要

GridDesk は、ローカル PC 上のファイル、フォルダ、アプリケーション、URL をジャンル別のセルグリッドに配置して管理する、個人向けローカルファイルランチャーです。

## 解決したい課題

デスクトップや通常のランチャーでは、案件別・用途別にファイルを自由配置しながら管理することが難しくなりがちです。ショートカットが増えると一覧性が落ち、PC 乗り換え時には登録情報の移行も手間になります。

GridDesk は、以下の課題を扱います。

- よく使うファイルやフォルダをジャンル別に整理したい
- デスクトップアイコンのように位置で覚えたい
- URL とローカルパスを同じ画面で扱いたい
- PC 乗り換え時に設定や配置をまとめて移行したい
- 個人開発や業務資料のショートカット集を軽く運用したい

## 通常のランチャーとの違い

| 項目 | 通常のランチャー | GridDesk |
| --- | --- | --- |
| 表示 | リストや検索中心 | ジャンル別セルグリッド |
| 配置 | 自動整列が中心 | セル上に自由配置 |
| 対象 | アプリ中心 | ファイル、フォルダ、URL も対象 |
| データ保存 | アプリ内部設定が多い | ワークスペースフォルダに集約 |
| 移行 | アプリごとの移行が必要 | ワークスペースコピーを基本にする |

## Obsidian Vault 的な考え方

GridDesk は、ユーザーデータを 1 つのワークスペースフォルダにまとめます。アプリ本体は UI と処理を提供し、登録データや設定はワークスペース側に保存します。

この方式により、次のような運用を目指します。

- ワークスペースフォルダをバックアップ対象にしやすい
- PC 乗り換え時にフォルダ単位で移行しやすい
- 複数の用途別ワークスペースを作れる
- アプリの更新とユーザーデータを分けて考えられる

## 想定ユーザー

- 個人開発者
- 業務資料や案件ファイルを多く扱うユーザー
- デスクトップアイコン型の配置に慣れているユーザー
- Obsidian、Excel、PDF、フォルダ、Web リンクをまとめて管理したいユーザー

## 想定ユースケース

- 案件別ファイルランチャー
- 業務資料のショートカット集
- 設計資料、マニュアル、ツール類の起動パネル
- 個人用の作業開始ダッシュボード
- PC 移行を見据えたファイル配置メモ

## MVP のゴール

MVP では、以下の基本動作を成立させることを目標にしています。

- ワークスペース作成/読込
- SQLite DB 作成
- ジャンル表示
- セルグリッド表示
- アイコン登録
- アイコン移動
- ダブルクリック起動
- セル削除/復活
- バックアップ作成

## 将来的な方向性

今後は、パスエイリアス編集、リンク切れチェック、検索、タグ、起動履歴、カスタムアイコン、エクスポート/インポートなどを追加し、PC 移行に強い個人用ランチャーとして育てていく予定です。
